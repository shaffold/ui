# docs-app template

A **scaffoldable documentation site** for a shadcn-style design system. The docs
chrome renders in the **same components the design system ships** — so the site
visually *is* the design system.

## How it works

One config file drives everything: **`components.json`** declares the design
system's `base` (base / radix / aria), `style` (nova / sera / …), `baseColor`,
`iconLibrary`, and the `@ds` registry the CLI/MCP read.

```
components.json ──(base+style)──► prebuild:styles ──► registry/ui/* ◄──(@/registry/ui/* alias)── chrome
  (source of truth)                (local build)       (built combo)        (docs render in that combo)
```

1. **Skeleton** (this step) — Next app + `components.json` + the
   `@/registry/ui/*` tsconfig alias + the neutral/nova `app/styles/theme.css`.
2. **Chrome** — the docs UI (sidebar, nav, code tabs, previews) authored against
   `@/registry/ui/*`, so it wears whatever `registry/ui` contains.
3. **Engine** (`scripts/build-style.mts`, run by `prebuild:styles`) — builds
   `registry/ui/*` for the chosen `base` + `style`. **nova** ships prebuilt;
   any other style is **fetched as `style-<name>.css` and built locally** via
   `transformStyle` + `createStyleMap` from `shadcn/utils`.

## Layout

```
components.json          # base + style + baseColor + @ds registry (source of truth)
tsconfig.json            # @/registry/ui/* -> ./registry/ui/* (the key alias)
app/
  globals.css            # tailwind + shadcn/tailwind.css + theme.css + @source
  styles/theme.css       # base-color + style CSS vars (generated per baseColor)
  layout.tsx  page.tsx
components/               # docs chrome (Step 2)
lib/utils.ts             # cn()
registry/ui/             # design-system components (generated by prebuild:styles — gitignored)
scripts/build-style.mts  # the local style-build engine (Step 3)
```

## Develop

```bash
pnpm install
pnpm prebuild:styles     # build registry/ui for the components.json base+style
pnpm dev
```

## Change the look

Edit `components.json` `style` (e.g. `nova` → `vega`) and re-run
`pnpm prebuild:styles` — the whole docs site re-themes with no chrome edits.
